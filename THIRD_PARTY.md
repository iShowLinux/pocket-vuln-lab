# Dependencies and attribution

The runtime uses only Python's standard library (including its bundled SQLite) and browser APIs. Frontend files, icon and learning copy are included locally; no CDN, analytics, external font or image requests are used.

Optional QA uses Playwright 1.64.0 (Apache-2.0) and the user's installed Chrome or a separately installed Playwright Chromium. QA dependencies and browsers are not included in the source ZIP. Python and installed browsers retain their own licenses.

CWE identifiers are explanatory labels from the Common Weakness Enumeration taxonomy. This project is independent training material, not an official MITRE or OWASP application or certification.
